# 音訊編輯視窗 + 音調 / 音 MAD

雙擊時間軸上的音訊片段，打開「音訊編輯視窗」（跟片段的編輯視窗同一個框架：`EditorWindow.tsx` 的開關、自己的復原紀錄、完成 / 取消，循環播放這個片段）。

## 1. 視窗內容

- 上方：放大的波形（左右聲道分開畫），照時間軸的規則：滾輪捲動、Ctrl + 滾輪縮放、中鍵拖曳（`wheelView.tsx`、`middlePan.ts`），可以拖曳選取一段範圍（沿用 `.marquee` 的樣式）
- 下方 / 左側：屬性
  - 音量、淡入 / 淡出（現有）
  - **聲道**：`Seg`：立體聲 / 只用左 / 只用右 / 左右對調 / 單聲道
  - **左右平衡（pan）**：-100 ~ 100
  - **音調**：半音 -24 ~ +24（跟速度分開，可以只改音調、不改速度）
  - 速度、保持音調（現有，從屬性面板搬進來一份）
- 選取一段範圍後 → 「加入區段」，這一段可以單獨設定音調、長度、音量（下面第 2 點）

## 2. 音符（音 MAD 的核心，像 Melodyne）

編輯視窗的波形上直接顯示音高：

- 縱軸是半音格線（左邊標 C4、D4…），自動偵測人聲的音高曲線（細線）
- 自動把聲音切成一個個**音符塊**（大約一個字一塊），放在它的平均音高上
- **上下拖音符塊** = 改這個字的音調（對齊半音，按住 Alt 不對齊）；↑ / ↓ 鍵一次一個半音；雙擊 = 還原
- 改過的音符塊和變調後的曲線用強調色畫
- （下一步）拖音符塊的左右邊緣 = 改長度（拖長音），同一軌後面的項目自動往後推
- 之後可以加：畫筆畫滑音 / 顫音、倒放、重複 N 次、音調對齊音階

## 3. 儲存格式（`AudioClip` 加可省略的欄位，舊專案不用轉換）

```ts
/** 聲道：沒設定 = 立體聲 */
channels?: 'left' | 'right' | 'swap' | 'mono';
/** 左右平衡 -1 ~ 1 */
pan?: number;
/** 整段的音調（半音），跟 rate 分開 */
pitch?: number;
/** 改過的音符：素材時間 a~b（秒，素材本身的時間，分割 / 修剪片段時不用改），依 a 排序、不重疊 */
regions?: { id: string; a: number; b: number; pitch?: number; stretch?: number; gain?: number }[];
/** 關鍵影格：volume / pan（音調改用音符，不用關鍵影格） */
keys?: Partial<Record<'volume' | 'pan', Keyframe[]>>;
```

- 關鍵影格的 `t` 用**片段內秒數**（跟片段一樣，才能直接用屬性面板的關鍵影格時間軸）；音符拉長時，後面的關鍵影格要跟著往後移
- 音調 = 整段 pitch + 那個位置的音符 pitch（半音）

- `duration` 仍然是時間軸長度；有區段時 = Σ(各段素材長度 × stretch) / rate
- 影片原音不做；要編輯就先「分離音訊」（已經有了），變成 AudioClip

## 4. 做法

- **變調、拉長都要保留原本的音色（聽起來還是同一個人）**：WSOLA + 重新取樣會連共振峰一起移動（花栗鼠感），所以不用。改用 **TD-PSOLA**：
  1. 偵測音高（YIN），找出每個聲門週期的位置（pitch marks）；
  2. 以每個週期為單位切成小段（2 個週期長的 Hann 窗）；
  3. **變調**：調整小段之間的間隔（間隔變小 → 音調變高），小段本身的形狀不變 → 共振峰（音色）不變；
  4. **拉長**：重複 / 跳過週期 → 長音很自然，不會像 WSOLA 拉太長時那樣抖；
  5. 沒有音高的部分（子音、氣音、靜音）用 WSOLA 處理，避免「ㄙ、ㄘ」變得怪怪的。
  - 純 TS、不需要模型。說話聲在 ±7 半音內效果好；超過 ±12 會開始不自然
  - 如果品質不夠，再換成 **WORLD 聲碼器**（WASM，modified BSD）：能分開控制音高、共振峰、長度，UTAU 類工具就是用這種方式，變調範圍更大，但聲音會稍微帶點「機器感」，而且要多一個 WASM 檔
- **處理過的聲音**：`audio.ts` 的 `sourceFor` 已經會把「保持音調的變速」先算成一段 buffer 並快取。擴充成：只要片段有 pitch / regions / channels / pitch 關鍵影格，就逐段算好接起來，用參數組成的 key 快取。預覽和匯出（`mixdown`）都走 `audioPlan` → 結果一樣
- 音量 / pan 的關鍵影格不用重算 buffer，直接在 `schedule` 裡排 `gain` / `pan` 的自動化曲線
- **pan**：在 `schedule` 裡加 `StereoPannerNode`（預覽和 OfflineAudioContext 都支援）
- **聲道**：算在處理過的 buffer 裡（不用 splitter）
- 計算放到 Worker，避免拖滑桿時卡住畫面；拖的時候先用上一個結果，放開再更新
- 純函式（變調、區段組合、長度計算）寫測試：`tests/audioFx.test.ts`

## 5. 分階段

1. ✅ 視窗 + 波形 + 聲道 / pan / 音量、pan 關鍵影格
2. ✅ PSOLA（音高偵測 + 變調）+ 整段音調
3. 音符：顯示音高曲線、自動切音符、上下拖改音調（音高分析搬到 Worker）；音調關鍵影格拿掉
4. 音符拉長 + 波紋推移
5. 音 MAD 的進階功能：畫筆、重複、倒放、對齊音階 / 對齊拍點

## 已決定

- 區段拉長 → 同一軌後面的項目自動往後推
- 音量 / pan 可以設關鍵影格；音調改成在波形上拖音符塊（像 Melodyne）
- 變調、拉長都要保留原本的音色 → 用 TD-PSOLA（品質不夠再換 WORLD）
