# 動畫圖層：修正去背、圖層自己的遮罩

目前：去背 = AI 算的 320×320 黑白遮罩（每張素材一份），畫圖層時直接拿來用，算錯了沒辦法改。
上一版加的「整體遮罩」是畫面座標，不跟著圖層動，拿來修去背不好用。

## 1. 修正去背（補上 / 擦掉）

在「圖片」列的去背開關旁邊加一個「修正去背」按鈕，打開一個視窗：

- 畫面顯示這張圖，去背掉的部分半透明紅色蓋著（看得出 AI 切到哪）。
- 工具：**補上**、**擦掉**，用鋼筆或筆刷畫範圍；可以復原、清除全部。
- 修正記在圖片位置上，座標是素材自己的（0~1），所以不管圖層怎麼縮放、移動、轉，修正都跟著。
- 渲染：上傳遮罩貼圖前，先把 AI 遮罩複製一份，照順序把「補上」塗白、「擦掉」塗黑（320×320 的 canvas，很便宜，有改才重算）。
- 剪影窗 / 主體挖洞這類用輪廓的範本也一起用修正後的遮罩。

儲存格式：`AnimSlot.cutout` 多一個可省略的欄位：

```ts
cutout?: {
  mode: 'auto' | 'off';
  outline?: string;
  /** 修正（依序套在 AI 遮罩上）；path 是素材 0~1 座標的 SVG 路徑，brush = 筆刷粗細（沒有 = 填滿的區域） */
  fix?: { op: 'add' | 'erase'; path: string; brush?: number }[];
};
```

## 2. 轉換成遮罩

同一個視窗裡的按鈕「轉換成路徑」：把 AI 遮罩描成路徑（簡化成幾十個點），之後完全用這條路徑去背，可以用鋼筆拉點修。
存成 `cutout.mode: 'path'` + `cutout.path`（素材座標的路徑和鋼筆錨點），AI 遮罩就不再使用。

## 3. 圖層自己的遮罩（跟著圖層動）

每個圖層區塊加「遮罩」（形狀、鋼筆、羽化、反轉、關鍵影格），座標以圖層本身為準：圖層縮放 / 移動時遮罩跟著。
`AnimLayer` 多一個可省略的欄位（舊的 `mask` 是剪影窗 / 挖洞用的，名字不同）：

```ts
clipMask?: { mask: Mask; keys?: Record<string, Keyframe[]> };
```

## 上一版的「整體遮罩」

畫面座標、不跟圖層動。可以留著（拿來切掉整個動畫的某一塊），也可以拿掉。

## 順序建議

1（補上 / 擦掉）最直接解決「AI 切錯」 → 3 → 2。
