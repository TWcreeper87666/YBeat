# 自動剪輯改版：編排視窗

生成後的每一個東西（切點、鏡頭用哪個素材、轉場、跳出、變速、特效）都看得到、改得到；每一項都可以是**自動**（隨機，照規則抽）或**指定**（固定，重抽不動）。

## 0. 核心概念：三層設定，每一項「自動 / 指定」

```
全域規則（分頁：素材 / 風格 / 特效）
  └ 分段規則（框一段歌，覆寫這段的規則）
      └ 單一項目（編排視窗裡的每個切點、鏡頭、轉場、跳出…）
          自動 = 照上面的規則隨機抽；也可以只改這一項的抽法（例如這個跳出只從「飛入 / 彈出」裡抽）
          指定 = 直接給值（這個跳出就是飛入、用這張圖）
```

- 跟片段特效的「作用」列一樣：在視窗裡動了某一項（拖、改屬性）→ 它自動變成**指定**；右鍵「改回自動」
- 畫法統一：自動 = 淡色 / 虛線外框（跟自動的副歌旗子一樣）；指定 = 實色 + 小圖釘
- 重抽只換自動的；要連指定的一起換用「全部重抽」

## 1. 面板（自動剪輯分頁）

```
┌───────────────────────────────────────────────┐
│ [✦ 產生] [再一版] [▦ 編排]   狀態 / 進度  ↺      │
├───────────────────────────────────────────────┤
│ 音樂  [歌 ▾] 0:12–1:40 ✎      128 BPM · 6 段   │
│ ┌───────────────────────────────────────────┐ │
│ │ 總覽：段落色帶 + 能量線 + 切點刻度 + 跳出標記 │ │  ← 點一下 = 打開編排並跳到那裡
│ └───────────────────────────────────────────┘ │     拖曳 = 試聽 scrub（跟現在一樣）
│ 切點 自動 · 42   鏡頭 3 指定   ▶  🎲          │  ← 摘要（狀態）
├───────────────────────────────────────────────┤
│ [素材] [風格] [特效]                           │  ← 全域規則，跟現在一樣
└───────────────────────────────────────────────┘
```

- 「分段」分頁拿掉 → 搬進編排視窗（分段是時間上的東西）
- 能量曲線的控制點、副歌旗子也搬進視窗；面板只留總覽 + 試聽（不想開視窗的人照樣能「產生」）
- 「整體強度 / 對比」留在面板（不是時間上的東西）

### 共通操作（照時間軸 / 作用列的規則，不另外發明）

- 滾輪捲動、Ctrl + 滾輪縮放、中鍵平移（`wheelView.tsx`、`middlePan.ts`），可以放大到 1/8 拍
- 點尺規 / 空白處拖 = 播放頭；Space 播放；歌播的時候預覽跟著播這一版
- 點選、Ctrl / Shift 多選、`.marquee` 框選；Delete、Ctrl+C / V / D、Ctrl+Z
- 拖曳吸附：吸附格線（1 拍 / 1/2 / 1/4 / 1/8 / 關）+ 鼓點（開關）；按住 Alt 暫時不吸附
- 右鍵選單：改回自動 / 指定、重抽這一個、刪除，加上各列自己的項目

### 各列

| 列 | 東西 | 操作 |
|---|---|---|
| 樂段 / 能量 / 副歌 | 現在面板上的那一套 | 曲線控制點、副歌旗子搬過來，操作不變 |
| 分段 | 框一段歌的規則覆寫 | 空白處拖 = 新增；選中後右邊屬性 = 現在 `ZonePanel` 的內容 |
| 切點 | 線、連切區塊、固定區塊 | 見下面 |
| 鏡頭 | 每個鏡頭一塊（縮圖 + 素材名） | 左右邊界就是切點（拖邊界 = 移動切點）；屬性：素材、起點、推近 / 拉遠、變速；從面板的素材清單拖進來 = 指定素材 |
| 轉場 | 每個切點一顆菱形（空的 = 硬切） | 屬性：轉場種類 / 硬切、長度；指定成硬切也算指定 |
| 跳出 | 固定寬度的方塊 | 跟切點列的固定區塊是同一個東西，這裡另外畫出主體 / 揭露縮圖 |
| 變速 | 鏡頭上的曲線記號 | 不定長的變速（每拍快慢、緩速…）是鏡頭的屬性；定長的（剪前倒抽…）是固定區塊 |
| 特效 1…n | 特效層產生的方塊（每層一列） | 拖、改長度、刪除；屬性：參數。第一版可以只做「刪除 / 改回自動」，見待決定 |
| 波形 | 歌的波形 + 鼓點刻度 | 只看 |

### 切點列

- **線**：雙擊空白處新增，拖曳移動，Delete = 那裡不切
- **連切區塊**：右鍵「加入連切」或 Shift + 拖曳框一段；方塊裡畫細線；屬性：
  - 方式 `Seg`：平均（N 刀）/ 跟拍（每 1/2、1/4… 拍）/ 跟鼓點（範圍內每個鼓點切一刀）
  - 右鍵「轉成切點」→ 展開成一條條的線
- **固定區塊**（剪前倒抽、倒播回正、正倒正、主體跳出）：寬度由種類決定，不能拖寬度，只能整塊移動、刪除；右鍵「加入 ▸ 剪前倒抽 / 主體跳出…」手動加
  - 自動：種類從規則裡抽（可以只改這一塊的候選種類）
  - 指定：種類固定；換種類 = 寬度跟著變（放不下就停在不重疊的最近位置）
- 切點不能進固定區塊；連切區塊不能跟固定區塊重疊

### 屬性欄（右邊）

- 最上面：種類名稱 + `Seg` [自動 | 指定]
- 自動：顯示「這一項的抽法」（候選種類、機率…，沒改過 = 照分段 / 全域規則，標「照規則」）+ 目前抽到什麼 + 「🎲 重抽這一個」
- 指定：直接給值（種類、素材縮圖、起點…）
- 多選：只顯示共同的欄位
- 沒選東西：這一版的統計（鏡頭數、平均長度、跳出 / 變速幾個）

### 重抽

- 工具列「🎲 重抽 ▾」：預設 = **重抽自動的**；選單裡另外有「全部重抽」（指定的也換掉，可以 Ctrl+Z）
- 每一列列名旁的 🎲 = 只重抽這一列（例如只換素材、切點不動）
- 每一列有自己的 seed，所以只換素材的時候切點、轉場、特效都不會跟著變

### 套用到時間軸

- 視窗裡每改一次就重新排這一版、直接更新時間軸上的這一個 take（延遲 0.3 秒合併），預覽馬上看得到；取消 = 回到開視窗前
- 素材分析、去背、AI 導演都用快取，不會每改一次就重跑；AI 導演只在「產生」時跑
- 開視窗時，這一版在時間軸上被手動改過（`canReplaceLast` 不成立）→ 問「從時間軸讀回」（用時間軸上的片段位置當成指定的切點、素材）或「用上一版」

## 3. 演算法

`planEdit` 拆成幾步，每一步有自己的 seed，指定的項目當成固定輸入：

1. **骨架**：固定區塊（跳出、定長變速）→ 切點（線、連切展開）
2. **鏡頭**：照骨架排素材、起點、推近 / 拉遠、不定長變速
3. **轉場**
4. **特效層**

要改的地方：
- 指定的切點不能被素材推動：影片太短時現在會縮短鏡頭（`b1--`），改成換一支夠長的；都不夠長就停在最後一格
- 指定的切點不受 `minShotSec` / `maxShotSec` 限制，最短一格畫面
- 固定區塊找不到適合的素材（例如沒有能去背的圖片）：變成普通的鏡頭，切點不動，區塊標成警告色
- 拍號允許小數（`12.25` = 第 12 拍後 1/4 拍）：`beatTime` 內插；用拍號查表的地方（`music.level`、`beats[b].down`、樂段）取整數部分
- 鼓點：`audioReact.ts` 已經有 `onsets()`（從波形找打擊點），export 出來給吸附和「跟鼓點」連切用

## 4. 儲存格式（`AeSong` 加可省略的 `board`）

```ts
/** 這一版的編排：自動的也存（重開專案看得到、重抽之外照樣重現）；pin = 指定 */
interface AeBoard {
  seeds: { cuts: number; shots: number; tr: number; fx: number };
  /** 切點（小數拍號） */
  cuts: { id: string; b: number; pin?: true }[];
  bursts: { id: string; b0: number; b1: number; by: 'n' | 'grid' | 'drum'; n?: number; grid?: number; pin?: true }[];
  /** 固定區塊；variant 沒有 = 自動抽，pick = 這一塊自己的候選 */
  blocks: { id: string; b0: number; kind: 'pop' | 'speed'; variant?: string; pick?: string[]; mediaId?: string; revealId?: string; pin?: true }[];
  /** 鏡頭：用 b0 對應到切點；只存指定的欄位 */
  shots: { b0: number; seg?: string; in?: number; motion?: 'in' | 'out' | null; speed?: string | null }[];
  /** 轉場：切點的拍號 → 種類（null = 硬切） */
  tr: { b: number; moduleId: string | null; beats?: number }[];
  /** 特效：刪掉 / 改過的（第一版可能只有刪掉） */
  fx: { lane: number; b0: number; off?: true }[];
}
interface AeSong { ...; board?: AeBoard }
```

- 沒有 `board` = 還沒產生過；「產生」= 照目前的 pin 重抽所有自動的
- 歌曲範圍或拍數變了 → 清掉 `board`（不做轉換）
- 分段、副歌照舊存在 `AeSong.zones` / `chorus`

## 5. 分階段

1. 演算法拆步驟 + 各自的 seed + 小數拍號（行為不變，測試照過）
2. `board` + 視窗骨架：尺規、波形、切點列、鏡頭列、屬性欄、即時套用
3. 固定區塊、連切、鼓點吸附、轉場列
4. 分段、能量曲線、副歌搬進視窗；面板改成總覽
5. 特效列
